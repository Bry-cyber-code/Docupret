Modèle

Réseaux sociaux (liens, facultatif)

Les coordonnées viennent de l'onglet Carte. Les e-mails n'acceptent que les polices courantes : la signature utilise Arial, lisible partout.

Installer dans Gmail
  1. Cliquez sur « Copier la signature ».
  2. Gmail → roue dentée → « Voir tous les paramètres ».
  3. Section « Signature » → « Créer » → collez (Ctrl + V).
  4. Si le logo n'apparaît pas : cliquez sur l'icône image et ajoutez le fichier signature-logo.png du kit.
  5. Enregistrez en bas de la page.
Installer dans Outlook
  1. Cliquez sur « Copier la signature ».
  2. Outlook → Paramètres → Comptes → Signatures.
  3. Créez une signature, collez-la, puis enregistrez.
Installer sur iPhone ou Mac
  1. Mac : Mail → Réglages → Signatures → « + », puis collez. Décochez « Toujours utiliser ma police par défaut ».
  2. iPhone : ouvrez le fichier signature.html du kit, sélectionnez tout, copiez, puis Réglages → Mail → Signature et collez.
